Site admin

Edit pages, convert Google Drive links, and check the visit counter, all from this one page. Nothing here touches a server you don't control: your token stays in this browser only.

About the token. To save changes, this page needs a GitHub fine-grained personal access token scoped to only the auntorchakma.github.io repository, with Contents: Read and write permission and nothing else. It's stored in this browser's localStorage and never sent anywhere except directly to GitHub's API. Click "Forget token" below before using a shared or public computer.

2. Edit a page

Loads the live file from GitHub. Saving commits directly to the repo; the public site updates within a minute or two.

3. Add a photo or video from Google Drive

Paste a Drive "Anyone with the link" share URL. This converts it to a direct-embed link you can paste into the editor above. It won't work for private files.

Image files embed directly. Video files over ~100MB may be slow to stream from Drive. For anything long, YouTube (unlisted) or a dedicated host will play more reliably.

A free, no-signup hit counter (visitorbadge.io) tracks page loads per file. This is a rough count, not real analytics, with no unique-visitor or location data. For that, add a free GoatCounter account later and I can wire it in.
